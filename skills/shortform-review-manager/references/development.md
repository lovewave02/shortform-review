# 프로젝트 운영과 개발 사이클

코드 개선·다음 과제 선정·인계를 요청받았을 때 읽는다. 검사와 판정 기록만 할 때는 필요 없다.

## 시작 확인

1. `git worktree list`로 같은 저장소의 체크아웃을 모두 확인한다. 설치된 스킬 링크가 가리키는 체크아웃과 실제 작업 브랜치의 worktree가 다를 수 있으므로, 작업 대상 브랜치가 있는 worktree에서 개발한다. 같은 프로젝트를 새로 clone하거나 새로 만들지 않는다.
2. 대상 worktree의 `git status`, `pyproject.toml` 버전, `AGENTS.md`, README, 로컬 인계 기록을 확인한다. 다른 도구의 미완료 변경은 보존한다.
3. 기준선으로 `.venv/bin/python -m unittest discover -s tests -v`를 실행하고 FFmpeg 통합 테스트가 생략됐는지 확인한다. `.venv`가 없으면 그 worktree 안에 만든다(`python3 -m venv .venv && .venv/bin/pip install -e .`).

## 과제 선정

우선 검증할 제품 가설: 영상·자막 검사 결과를 한곳에서 보면 검토 시간이 줄어든다. 다음 순서로 후보를 찾는다.

- 실제 제작 검사 기록(`triage.md`)에서 판정이 막힌 지점, 오탐·누락, 불완전 검사 표시 오류
- 보고서에서 문제 구간을 찾아가고 확인하는 과정의 불편
- README 설명과 실제 CLI·코드 동작의 불일치

하나만 고른다. 정당한 결함이나 기능 공백이 없으면 억지 기능을 넣지 않고 비교 결과와 다음 검증 항목만 남긴다. 비교 대상(MediaQCTool, ai-video-qc, Subtitle Edit, ffmpeg-normalize)보다 낫다는 주장은 실제 동등 조건 실행 없이 하지 않는다.

## 개발 사이클

재현 → 설계 → 최소 구현 → 회귀 검증 → 문서화 순서로 진행한다.

- 재현: 합성 MP4/SRT를 gitignored `.local-runs/<과제>/`에 만들고 수정 전 동작을 기록한다. 실제 제작 파일은 사용자가 지정한 것만 쓴다.
- 책임 분리: 파서(`srt.py`), 미디어 검사(`media.py`), 규칙(`rules.py`), 보고서(`reports.py`), 오케스트레이션(`review.py`), CLI(`cli.py`). 공개 JSON 필드를 바꾸면 `SCHEMA_VERSION`을 올리고 README에 적는다.
- 회귀 테스트: 새 테스트가 수정 전 코드에서 실패하는지 확인한다(예: `git archive HEAD src`를 임시 폴더에 풀고 `PYTHONPATH`로 실행).
- HTML 동작 변경: 단위 테스트 외에 실제 브라우저에서 확인한다. 브라우저 자동화가 `file:`을 막으면 보고서 폴더를 `127.0.0.1`의 빈 포트로 임시 서빙하고, 끝나면 서버와 스크린샷·스냅샷 산출물을 정리한다. CSP 콘솔 오류가 0인지 본다.
- 문서: README(사용자 동작), DESIGN.md(보고서 설계 이유), 이 스킬(검토 절차)에 필요한 만큼만 반영한다.

## 제품 원칙(변경 금지 경계)

- 탐지는 검토 후보다. 의도된 무음·검은 화면을 오류로 확정하거나 자동 제거하지 않는다.
- 검사 실패·생략을 정상 검사로 표시하지 않는다. `clean`은 납품·게시 승인이 아니다.
- SRT 검사로 번인 자막·음성 정렬·언어 품질을 검증했다고 말하지 않는다.
- 원본 미디어와 기존 보고서를 덮어쓰지 않는다. 임계값을 결과가 깨끗해 보이도록 조정하지 않는다.

## 인계와 공개 경계

- 작업 종료 시 메인 체크아웃의 로컬 `HANDOFF.md`(비공개, 저장소 비추적)에 날짜·브랜치·worktree 경로·실행한 검사·남은 한계·다음 한 가지를 덧붙인다. 실행하지 않은 검사를 PASS로 쓰지 않는다.
- 커밋·푸시·태그·릴리스·패키지 배포·이슈 작성·외부 연락·OSS 지원 신청은 현재 요청에서 별도 승인을 받은 경우에만 한다. 이전 세션 승인은 이어지지 않는다.
- 지원 프로그램 기준은 신청 판단 시점에 공식 페이지를 새로 확인한다. 스타·다운로드·테스트 성공을 수요나 선정 가능성으로 해석하지 않는다.
